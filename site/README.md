# AkademiX — Bootstrap Album Giriş Sayfası

## Nasıl çalıştırılır?
1. `akademix-album` klasörünü Visual Studio Code ile açın.
2. `index.html` dosyasını açın.
3. **Live Server** eklentiniz varsa dosyaya sağ tıklayıp **Open with Live Server** seçin. Alternatif olarak `index.html` dosyasına çift tıklayarak tarayıcıda açabilirsiniz.
4. Bootstrap 5.3.3 CDN bağlantıları kullanıldığından Bootstrap stilleri ve açılır menünün düzgün çalışması için internet bağlantısı gerekir.

## Dosyalar
- `index.html`: HTML yapısı, Bootstrap bileşenleri ve demo form davranışı.
- `style.css`: Özel renkler, kart görünümü, hover efekti ve mobil kurallar.

## Ders notlarıyla ilişkisi
- s.4: `header`, `nav`, `main`, `section`, `article`, `footer` semantik etiketleri.
- s.6: `table`, `form`, `label`, `input`, `select`.
- s.12: Bootstrap CDN ve CSS dosyalarının doğru sıralaması.
- s.13–15: `container`, `row`, `col`, `card`, `btn`, `badge`, spacing sınıfları.
- s.19: CSS değişkenleri, hover, media query.
- s.24: Navbar + hero + en az 3 kart + tablo + form + footer.

## Not
Ön kayıt formu yalnızca demo amaçlıdır. Bir sunucu/veritabanına gerçek başvuru iletmez.

Tasarım referansı: https://getbootstrap.com/docs/5.3/examples/album/
